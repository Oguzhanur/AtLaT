# 🎮 AtLaT Game

AtLaT is a 2D game developed using C++17 and raylib.
It features a custom tilemap architecture and cross-platform
support for Windows and Linux.

---

## 🛠️ Tech Stack & Dependencies

* **Language:** C++17 / C
* **Build System:** CMake (Version 3.16+)

## 📚 Third-Party Libraries

* [raylib](https://www.raylib.com/) — C/C++ library for game programming and graphics rendering.
* [cute_tiled](https://github.com/RandyGaul/cute_headers/blob/master/cute_tiled.h) — Lightweight Tiled map parser (`cute_tiled.h`).
